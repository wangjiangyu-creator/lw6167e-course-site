# LW6167E Course Companion

Open `index.html` in a browser to view the local static course companion.

The site uses:

- `course-data.js` as the structured course data source
- `app.js` for filtering and rendering
- `styles.css` for responsive layout
- `assets/order-map.svg` as the course logic diagram
